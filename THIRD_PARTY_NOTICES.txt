Windows desktop dependencies
----------------------------
The Windows tray build also uses pystray (LGPL-3.0), Pillow (MIT-CMU), and
pyperclip (BSD-3-Clause). Their installed license texts are collected into
the desktop bundle under licenses/licenses.txt, alongside all other bundled
Python dependencies. The unmodified versions are pinned in
requirements-windows.txt. Upstream source distributions are available at:
https://pypi.org/project/pystray/0.19.5/
https://pypi.org/project/pillow/12.3.0/
https://pypi.org/project/pyperclip/1.11.0/
The full draft-kit source and build scripts allow the bundle to be rebuilt
with replacement library versions. Refer to each dependency's own license.
